# API 키 설정 매뉴얼

고치갑서는 키가 없어도 모든 분석 기능이 동작합니다(키 없는 모드: 정해진 문장과 버튼으로 묻고, 이동 시간은 직선거리로 추정).
키를 넣으면 문장으로 묻기·대화 해석과 에이전트 판단(LLM), 실제 도로 이동 시간, 카카오 지도가 켜집니다.

> **평가용 제출 ZIP**에는 사용 한도를 건 평가용 키가 `.env`에 이미 들어 있습니다. 평가할 때는 아무것도 바꾸지 않고 `run.bat`만 실행하면 됩니다. 평가용 키는 평가가 끝나면 폐기합니다.

## 1. 키 목록

| 키 | 쓰는 곳 | 키가 없을 때 | 제출 ZIP |
|---|---|---|---|
| `LLM_API_KEY` | 문장 질문·대화 해석, 하위 에이전트 판단, 설명 다듬기 | 정해진 문장·버튼(규칙)으로 동작 | 평가용 키 입력 |
| `KAKAO_REST_KEY` | 실제 도로 이동 시간, 코스 식당·숙소 좌표, 장소 주변 가게 검색 | 직선거리 추정, 주변 가게는 오픈스트리트맵(Photon) | 평가용 키 입력 |
| `KAKAO_JS_KEY` | 화면 지도 | 인터넷 없이 그리는 기본 지도 | 평가용 키 입력 |
| `VISITJEJU_KEY` | 비짓제주 사진 목록 다시 받기 (자료 갱신용) | 받아 둔 CSV를 그대로 씀 | 비움 |
| `KTO_KEY` | 한국관광공사 무장애 식당 목록 다시 받기 (자료 갱신용) | 받아 둔 CSV를 그대로 씀 | 비움 |
| `JEJU_DATAHUB_KEY` | 지금은 쓰지 않음 (데이터허브 무장애 자료는 공개 파일로 키 없이 받음) | — | 비움 |

데이터 API 키(`VISITJEJU_KEY`, `KTO_KEY`, `JEJU_DATAHUB_KEY`)는 제출물에 넣지 않습니다. 앱을 실행할 때는 필요 없고, 자료를 새로 받을 때만 씁니다.

## 2. 키 넣는 방법

1. 프로그램 폴더의 `.env` 파일을 마우스 오른쪽 단추로 눌러 [연결 프로그램] → [메모장]으로 엽니다.
2. 맨 위 세 줄(`LLM_API_KEY`, `KAKAO_REST_KEY`, `KAKAO_JS_KEY`)의 `=` 뒤에 발급받은 키를 붙여 넣습니다. 띄어쓰기나 따옴표는 넣지 않습니다.
3. 저장한 뒤, 실행 중인 검은 창을 닫고 `run.bat`을 다시 실행합니다.
4. 화면 오른쪽 위의 '센터 자료·설정'을 열어 LLM 칸에 `API · openai/gpt-6-luna`가 보이면 연결된 것입니다. '키 없음'이 보이면 키 값을 다시 확인합니다.

키가 들어 있는 `.env`는 메신저·메일·코드 저장소에 올리지 않습니다. `.env.example`은 빈 견본이므로 키를 넣지 않습니다.

## 3. 키 발급 방법

### LLM (OpenRouter)

1. openrouter.ai에 가입하고 로그인합니다.
2. 크레딧을 충전합니다(사용한 만큼 차감).
3. Keys 메뉴에서 새 키를 만듭니다. 키마다 사용 한도(credit limit)를 정해 두기를 권장합니다.
4. 만든 키를 `LLM_API_KEY`에 넣습니다. 기본 모델은 `openai/gpt-6-luna`입니다.

다른 공급자로 바꿀 때는 `.env`의 세 줄만 바꿉니다. 코드는 고치지 않습니다.

| 공급자 | `LLM_BASE_URL` | `LLM_MODEL` | `LLM_API_KEY` |
|---|---|---|---|
| OpenRouter (기본) | `https://openrouter.ai/api/v1` | `openai/gpt-6-luna` (openrouter.ai 모델 목록의 `회사/모델` 이름) | OpenRouter 키 |
| OpenAI 직접 | `https://api.openai.com/v1` | OpenAI 모델 이름 | OpenAI 플랫폼에서 받은 키 |
| Gemini·Claude | 각 회사의 OpenAI 호환 주소 | 각 회사 모델 이름 | 각 회사에서 받은 키 |

바꾼 모델이 function calling을 지원하지 않으면 `LLM_TOOL_CALLING=off`로 둡니다. 이때 하위 에이전트는 규칙으로 판단합니다.

### 카카오 (REST 키·JavaScript 키)

1. developers.kakao.com에 로그인 → 내 애플리케이션 → 애플리케이션을 추가합니다.
2. 앱 키 화면에서 **REST API 키**를 `KAKAO_REST_KEY`에, **JavaScript 키**를 `KAKAO_JS_KEY`에 넣습니다.
3. 같은 앱의 플랫폼 → Web에 `http://localhost:8501`과 `http://127.0.0.1:8501`을 등록합니다.
4. 제품 설정 → 카카오맵에서 사용 설정을 ON으로 켭니다(새로 만든 앱은 꺼져 있음). 켜지 않으면 지도 자리에 '카카오맵을 불러오지 못했습니다' 안내가 나옵니다.

길찾기(카카오모빌리티)와 장소 검색의 사용량 한도·이용 조건은 카카오 개발자 콘솔에서 확인합니다. 키가 없거나 호출이 실패하면 직선거리 추정치를 쓰고 화면에 '추정'으로 표시합니다. 버스는 늘 추정치입니다.

### 자료 다시 받기용 데이터 API 키 (선택)

받아 둔 자료가 프로그램에 이미 들어 있으므로, 자료를 최신으로 바꾸고 싶을 때만 필요합니다.

- **`KTO_KEY`**: 공공데이터포털(data.go.kr)에 로그인 → '한국관광공사_무장애 여행 정보'(15101897)를 활용 신청 → 마이페이지의 개발계정에서 일반 인증키를 복사해 넣습니다(Encoding·Decoding 어느 쪽이든 됨). 승인 직후에는 1시간쯤 걸릴 수 있고, 하루 1,000회까지 부를 수 있습니다.
  넣은 뒤 프로그램 폴더에서 `.venv\Scripts\python scripts\fetch_kto_barrierfree.py`를 실행하면 `data\public\kto_bf_restaurant.csv`를 새로 만듭니다.
- **`VISITJEJU_KEY`**: 비짓제주 관광정보 Open API 키를 발급받아 넣습니다.
  넣은 뒤 `.venv\Scripts\python scripts\fetch_visitjeju.py`를 실행하면 이름·좌표(2km 안)로 장소와 짝을 맞춰 `data\visitjeju\visitjeju_photos.csv`를 새로 만듭니다. 출력된 짝에 엉뚱한 장소가 없는지 눈으로 확인합니다.
- 제주데이터허브 무장애 자료는 키 없이 공개 파일로 받습니다(`data\down_script.py`, 자세한 방법은 `data\README.md`).

## 4. 비용 보호 설정

`.env`에 있으며, 기본값 그대로 써도 됩니다.

| 설정 | 기본값 | 뜻 |
|---|---|---|
| `LLM_MAX_CALLS_PER_QUESTION` | 12 | 질문 하나당 LLM 호출 상한. 넘으면 그 질문의 나머지는 규칙으로 처리 |
| `LLM_MONTHLY_BUDGET_USD` | 20 | 월 예산(달러). 넘으면 그달은 자동으로 키 없는 모드 |
| `LLM_CACHE` | on | 같은 질문은 저장된 답을 다시 써서 비용 0 |
| `AGENT_LLM` | on | 하위 에이전트(데이터 탐색·접근성 진단·코스 설계·현황 분석)가 LLM으로 도구와 조건을 고름. off면 규칙 판단만 |
| `AGENT_MAX_STEPS` | 4 | 하위 에이전트 한 번의 판단 단계 상한 |
| `LLM_TOOL_CALLING` | on | 오케스트레이터가 확인된 분석을 도구(function calling)로 부름 |
| `LLM_REASONING_EFFORT` | low | 모델의 생각 깊이. 높일수록 느리고 비쌈 |

골든 질문셋(55문항)으로 잰 기본 모델의 비용은 질문당 평균 6.3회 호출, 약 0.0011달러입니다. 질문 1,000건에 약 1.1달러이므로, 월 예산 20달러로 약 1만 7천 건을 처리할 수 있습니다.
'센터 자료·설정' 화면에 이번 달 예상 비용이 나오고, 호출별 토큰 수와 예상 비용은 `runtime\llm_usage.jsonl`에 남습니다(데이터 내용은 남기지 않음). 모델별 예상 단가는 `config\models.yaml`에 있으며, 실제 청구는 공급자 기준입니다.

## 5. 밖으로 보내는 정보

- **외부 LLM**: 질문 문장, 조건 요약(예: "수동 휠체어, 장애인 화장실 필요"), 지역 이름, 계산 결과의 집계 요약. 대화 중이면 지금 코스의 장소 이름, 최근 질문 4개, 직전에 되물은 질문이 함께 갑니다.
  조건 세 단계 입력(시작하기)은 질문 해석에 LLM을 쓰지 않습니다.
- **카카오·Photon·위키미디어**: 장소 좌표나 가게 주소만 보내고, 이용자 조건은 보내지 않습니다. 카카오 응답은 파일로 저장하지 않으며, 길찾기 결과는 메모리에만 최대 6시간 둡니다.
- **보내지 않는 것**: 관광지 조사 원본 값, 센터 CSV 원본 행, API 키, 기록 속 이용자 조건('(조건)'으로 가려서 기록).

## 6. 선택 기능

- **음성 입력** (`STT_MODE=api`, `STT_MODEL`): 대화창에 '말로 물어보기'가 생기고, 음성이 음성 인식 API로 전송됩니다. 그래서 기본은 꺼져 있습니다(`off`). OpenRouter에는 음성 인식 기능이 없을 수 있어, 쓰려면 OpenAI 직접 키(`LLM_BASE_URL=https://api.openai.com/v1`)를 권장합니다. PC에 마이크가 있어야 합니다.
- **장소 주변 사진·볼거리·가게** (`PLACE_INFO_ONLINE`): 기본 1. 인터넷이 없는 PC라면 0으로 두면 부르지 않습니다.
