고치갑서 — 무장애 제주 여행 에이전트

실행 방법 (Windows 10/11)
  1. 이 폴더의 run.bat 을 더블클릭합니다.
     처음 한 번은 설치가 함께 진행됩니다(3~10분, 인터넷 필요).
     파이썬 3.12가 없으면 이 사용자 계정에 자동으로 설치합니다(관리자 권한 필요 없음).
     파란 창 "Windows의 PC 보호"가 뜨면 [추가 정보] → [실행]을 누릅니다.
     (인터넷에서 받은 실행 파일이라 윈도우가 한 번 묻는 것입니다.)
     검은 창이 함께 뜨는 것은 정상입니다. 설치·실행 상황이 거기에 나옵니다.
  2. 브라우저가 저절로 열립니다. 안 열리면 주소창에 http://localhost:8501 을 입력합니다.
  3. 끝낼 때는 검은 창을 닫습니다.

설정
  - API 키는 이 폴더의 .env 파일에 들어 있습니다(평가용, 사용 한도 설정됨).
  - 키가 없거나 비워 두면 키 없는 모드(정해진 문장·버튼)로 실행됩니다.
  - 인터넷으로 연결하는 외부 주소와 자세한 설명: README.md, docs\llm-setup.md
